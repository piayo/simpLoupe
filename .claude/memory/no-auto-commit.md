**git の commit / push / PR 作成は、明示的に指示されたときだけ行う。** 作業が一区切りついても、
勝手にコミットしてはいけない。変更は未コミットのまま残し、「コミットしますか」と尋ねる。

**Why:** 姉妹プロジェクトで、作業の流れのまま確認せずに commit / push / PR 作成まで進めてしまい
指摘された。過去に「関係あるごとに分けて commit/push をお願いします」と言われたことがあったが、
あれはその時点の依頼であって、以後ずっとコミットしてよいという常時許可ではなかった。

公開済みの拡張機能のリポジトリであり、履歴に残る操作は本人が判断する。
特にコミットメッセージは push すると取り返しがつかない（ユーザー共通の CLAUDE.md 参照）。

**How to apply:** 変更を書いたら未コミットのまま「以下を変更しました。コミットしますか」と報告する。
`git add` / `git commit` / `git push` / `gh pr create` はいずれも指示待ち。
コミット単位の分け方を提案するのはよいが、実行はしない。
